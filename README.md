# 🤖 Discord AI-Помощник по Регламенту и Правилам Сервера

Интеллектуальный Discord-бот на **Python (`discord.py`)** с интеграцией нейросети **Google Gemini**. Бот обучен на правилах вашего сервера, регламенте администрации и FAQ. Он моментально и вежливо отвечает на вопросы игроков, ссылается на конкретные пункты правил и помогает разгрузить команду модераторов.

---

## 🌟 Основные возможности

- 🧠 **Умные ответы на базе ваших правил**: Бот знает весь регламент сервера и цитирует пункты (например, *«Согласно п. 2.4 правил проекта...»*).
- ⚡ **Слэш-команды (`/`)**:
  - `/ask <вопрос>` — задать вопрос нейросети по правилам или игре.
  - `/rules` — интерактивная памятка по разделам правил.
  - `/faq` — список часто задаваемых вопросов с кнопками.
  - `/reload_rules` — моментальная перезагрузка базы знаний из файлов без перезапуска бота (доступно только администраторам).
- 💬 **Общение в чате и ветки (Threads)**: 
  - В выделенном канале помощи (`HELP_CHANNEL_ID`) бот **автоматически создает отдельную ветку (Thread)** на каждое сообщение игрока и отвечает внутри неё, не засоряя основной чат!
  - Если игрок продолжает задавать вопросы внутри созданной ветки, бот продолжает диалог прямо там.
  - В любых других каналах бот отвечает при прямом упоминании `@ИмяБота <вопрос>`.
- 📁 **Простая база знаний**: Все правила лежат в удобных текстовых файлах в папке `knowledge/` (`rules.md`, `faq.md`). Вы можете просто открыть их в Блокноте и вписать правила вашего сервера!
- 🛡️ **Защита от выдумок (гарантия фактов)**: В промпт заложена строгая инструкция — не выдумывать несуществующие правила и отправлять в тикет-систему, если регламент не описывает ситуацию.

## 🚀 Быстрый старт и настройка

### Шаг 1. Получение токена Discord Бота
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и войдите в свой аккаунт.
2. Нажмите кнопку **«New Application»** в правом верхнем углу, введите название (например, `Server Assistant`) и подтвердите.
3. В левом меню выберите вкладку **«Bot»**:
   - Нажмите **«Reset Token»**, подтвердите и скопируйте полученный токен (это `DISCORD_TOKEN`).
   - Прокрутите страницу вниз до раздела **«Privileged Gateway Intents»** и обязательно включите:
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent** *(обязательно для чтения вопросов!)*
   - Нажмите зелёную кнопку **«Save Changes»** внизу.
4. Перейдите во вкладку **«OAuth2»** -> **«URL Generator»**:
   - В блоке **SCOPES** отметьте галочками: `bot` и `applications.commands`.
   - В блоке **BOT PERMISSIONS** отметьте: `Administrator` (или минимально: `Send Messages`, `Send Messages in Threads`, `Create Public Threads`, `Embed Links`, `Read Message History`, `View Channels`, `Use Slash Commands`).
   - Скопируйте ссылку внизу (Generated URL) и откройте её в браузере, чтобы пригласить бота на ваш Discord сервер.

---

### Шаг 2. Получение бесплатного ключа Google Gemini API
1. Перейдите на [Google AI Studio](https://aistudio.google.com/).
2. Войдите через ваш Google-аккаунт.
3. Нажмите кнопку **«Get API key»** -> **«Create API key»**.
4. Скопируйте полученный ключ (он бесплатный и не требует привязки банковской карты).

---

### Шаг 3. Настройка файла `.env` и канала с ветками
Откройте файл `.env` в корне папки `discord-helper-bot` в любом текстовом редакторе (Блокнот, VS Code) и укажите ваши ключи:

```env
DISCORD_TOKEN=ваш_токен_дискорд_бота
GEMINI_API_KEY=ваш_ключ_gemini_api
SERVER_NAME=Название Вашего Сервера

# (По желанию) ID канала, где бот будет отвечать ветками на каждое сообщение:
HELP_CHANNEL_ID=123456789012345678

# Защита от спама и лимиты запросов от одного игрока:
RATE_LIMIT_MAX_REQUESTS=5        # максимум 5 вопросов
RATE_LIMIT_WINDOW_SECONDS=86400  # в день (24 часа = 86400 сек)
RATE_LIMIT_COOLDOWN_SECONDS=60   # пауза (кд) между вопросами (60 сек)
```

#### 📌 Как узнать ID канала для `HELP_CHANNEL_ID`:
1. В Discord откройте **Настройки пользователя** (шестерёнка внизу слева).
2. Перейдите во вкладку **«Расширенные»** (Advanced) и включите переключатель **«Режим разработчика»** (Developer Mode).
3. Нажмите правой кнопкой мыши по нужному текстовому каналу (например, `#помощь` или `#вопросы`) и выберите **«Скопировать ID канала»**.
4. Вставьте это число в поле `HELP_CHANNEL_ID=` в файле `.env`.
5. Теперь любое сообщение в этом канале автоматически превратится в отдельную ветку с подробным ответом ИИ!

---

### Шаг 4. Настройка правил сервера
1. Зайдите в папку `knowledge/`.
2. Отредактируйте файл `rules.md`: вставьте туда реальные правила вашего сервера. Чем четче пронумерованы пункты (например, 1.1, 1.2, 2.1), тем точнее бот будет на них ссылаться.
3. Отредактируйте `faq.md` для частых вопросов (как зайти, сайт, магазин, донат).
4. Если вы измените правила во время работы бота, просто напишите в Discord слэш-команду `/reload_rules`, и бот мгновенно обновит знания без перезапуска!

---

### Шаг 5. Запуск бота
- **Простой способ (Windows):** дважды кликните по файлу `run.bat`.
- **Через терминал:**
  ```powershell
  cd C:\Users\knjazxx\.gemini\antigravity\scratch\discord-helper-bot
  .\venv\Scripts\python.exe bot.py
  ```

После запуска в консоли появится сообщение:
`Бот успешно авторизован как Assistant#1234`
`Синхронизировано слэш-команд: 4`

В Discord на вашем сервере введите `/ask` и протестируйте ответ!
